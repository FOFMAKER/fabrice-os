# Fabrice's OS

Career operating system for **Fabrice Fidel** — Product Designer · Product Builder · Technical Innovator.

This is a personal brand site, not a portfolio and not a résumé. Visual language follows [tusharnath.online](https://tusharnath.online): narrow column, quiet type, terminal chrome, command chips, ⌘K.

It is a **standalone project**. It does not live in ParkTracker.
